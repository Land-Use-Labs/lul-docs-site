Authentication

Every request needs an API key. One key works for every endpoint. Each key belongs to your organization's plan, which sets what you can access and how much you can use it.

Sending your key​

Send the key in the Ocp-Apim-Subscription-Key header:

curl -G 'https://api.landuselabs.com/api/v1/point' \
  --data-urlencode 'lat=39.987446' \
  --data-urlencode 'lon=-105.089973' \
  -H 'Ocp-Apim-Subscription-Key: YOUR_KEY'

Or as the subscription-key query parameter, which is handy for a quick test in a browser:

https://api.landuselabs.com/api/v1/point?lat=39.987446&lon=-105.089973&subscription-key=YOUR_KEY

Use the header in anything you build. A key in a URL can end up in browser history, server logs, and shared links.

Contact us.

Keeping your key secure​

  • Keep your key on your server. Anyone can read a key embedded in browser or mobile app code.
  • Don't commit keys to version control.
  • If a key is exposed, contact us and we'll issue a new one.

Authentication errors​

A missing or invalid key returns 401. The message says which. See Errors.
