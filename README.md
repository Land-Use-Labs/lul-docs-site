# Land Use Labs — API documentation (published site)

**https://land-use-labs.github.io/lul-docs-site/**

This repository contains **generated output only** — the built HTML, CSS and JavaScript
for the documentation site. It is force-pushed on every publish, so any change made
here directly will be overwritten.

Nothing in this repository is edited by hand.

## Where the source lives

The site is built from a separate, private repository (`Land-Use-Labs/lul-docs`), which
holds the content, the styling and the build configuration. Documentation changes are
made there and published from there.

If you have spotted a problem with the docs, please raise it with the Land Use Labs
team rather than opening a pull request here — there is nothing in this repository to
change.

## What the site covers

Reference documentation for the Land Use Labs Zoning API, generated from the API's own
OpenAPI description, alongside written guides.

Learn more at [landuselabs.com](https://landuselabs.com).
