Land Use Labs Zoning API

The Zoning API returns the zoning districts in force at a point, together with the regulations attached to them — use treatments, parking requirements, setbacks, building heights and more.

A point is given either as a coordinate pair or as an address; the API geocodes addresses itself and reports back the coordinate it settled on.

curl -G 'https://lul-api-prod.azure-api.net/api/v1/point' \
  --data-urlencode 'addr=1290 S. Public Road Lafayette, CO 80026' \
  --data-urlencode 'subscription-key=YOUR_KEY'

Authenticating​

Every request needs a subscription key. Send it either as a query parameter:

curl -G 'https://lul-api-prod.azure-api.net/api/v1/point' \
  --data-urlencode 'addr=1290 S. Public Road Lafayette, CO 80026' \
  --data-urlencode 'subscription-key=YOUR_KEY'

…or as a header:

curl -G 'https://lul-api-prod.azure-api.net/api/v1/point' \
  --data-urlencode 'lat=39.987446' --data-urlencode 'lon=-105.089973' \
  -H 'Ocp-Apim-Subscription-Key: YOUR_KEY'
